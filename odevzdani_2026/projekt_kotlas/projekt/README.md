# Zdrojové kódy — Jiří Kotlas

Zdrojové kódy projektu **Project Manager** byly zkontrolovány vedoucím práce Ing. Adamem Ferenczem.

Na základě dohody se studentem nebudou zdrojové kódy zveřejněny v tomto repozitáři, neboť aplikace obsahuje citlivé obchodní a organizační prvky určené pro reálné nasazení.

Zdrojový kód byl předán a ověřen osobně při konzultaci.
